# Столовая «Вкусный обед»

Проект по ООП (летняя практика, 1 курс)

## О проекте

Программа имитирует работу столовой. Посетители приходят, берут расходные материалы (подносы, вилки, ложки, салфетки), выбирают блюда на раздаче, оплачивают на кассе, садятся за столики (одиночно или группами), а после еды относят грязную посуду в специальное окно. Процесс визуализируется в реальном времени, все параметры настраиваются через файл конфигурации.

## Структура проекта

- `Main.java` — графический интерфейс на JavaFX
- `Stolovaya.java` — управление симуляцией
- `Chelovek.java` — класс посетителя
- `Stol.java` — класс столика
- `Blyudo.java` — класс блюда
- `Razdacha.java` — очередь к раздаче
- `Kassa.java` — очередь к кассе
- `Okno.java` — окно грязной посуды
- `Rabotnik.java` — родительский класс работников
- `Povar.java` — класс поварёнка (наследник Rabotnik)
- `Posudomoy.java` — класс посудомоя (наследник Rabotnik)
- `Statistika.java` — вывод статистики

## Принципы ООП

- **Инкапсуляция** — все поля классов приватные, доступ через геттеры и специальные методы (incrementObsluzheno и др.)
- **Наследование** — классы `Povar` и `Posudomoy` наследуют общий класс `Rabotnik`
- **Полиморфизм** — метод `rabotat()` переопределён в наследниках, вызывается единообразно через родительский тип

## Функциональность

- Возможно загрузка параметров из файла  (количество столов, блюд, цен, вероятностей, расходников)
- Генерация одиночных и групповых посетителей
- Выбор блюд с учётом предпочтений и доступных денег
- Оплата на кассе (с проверкой достаточности средств)
- Поиск стола с возможностью сдвигать столы для групп
- Поварёнок пополняет блюда и расходные материалы
- Посудомой убирает грязную посуду
- Отображение схемы столовой с посетителями, очередями и расходниками
- Статистика по нажатию кнопки (обслужено, ушли без денег/блюд/расходников)

## Запуск

Для запуска требуется JavaFX SDK. Настройте VM options:

--module-path "путь_к_javafx/lib" --add-modules javafx.controls,javafx.fxml

После запуска откроется графическое окно с кнопками управления: Старт, Пауза, Стоп, Статистика. При нажатии «Статистика» справа появляется детальный отчёт по работе столовой.
